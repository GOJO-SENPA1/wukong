Fonts used to draw the site's share images (`opengraph-image` routes, see
`src/lib/og.tsx`). They are the same families the site loads through
`next/font`: Anton, Instrument Serif, Instrument Sans and JetBrains Mono, all
under the SIL Open Font License 1.1 (license texts alongside), downloaded as
static TrueType files from Google Fonts because the image renderer can't read
WOFF2 or variable fonts.
